# Contribution policy

This clean-room repository currently accepts implementation commits authored
and committed only by `btlqql <2977859784@qq.com>`.

Do not submit copied patches, cherry-picks, generated rewrites of another
RWKV-7 vLLM implementation, or commits carrying another author, committer, or
`Co-authored-by` identity. Public algorithm specifications and documented
upstream APIs may be reported as references without making their maintainers
contributors to this repository.

The CI provenance check validates the complete Git history. Design discussion
and reproducible bug reports are welcome, but code changes remain under the
single-author clean-room policy while it is active.
